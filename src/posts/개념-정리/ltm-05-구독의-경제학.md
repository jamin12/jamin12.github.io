Mem0 클라우드 판을 쓰지 않고 오픈소스 서버를 맥 안에 올리면 기능 목록에서 여러 줄이 사라진다. 자동 분류, 요약 API, 리랭커, 웹훅, 내보내기 API가 그 줄들이다.

메운 자리는 셋으로 갈린다. **세션 밖**은 훅과 launchd가 부르는 헤드리스 `claude -p`, **세션 안**은 MCP 도구를 쥔 채 대화 중인 Claude 자신, **서버**는 LLM이 아니라 숫자 하나를 내는 작은 모델이다.

| 클라우드 기능 | 로컬 상태 | 어떻게 메웠나 | 방식 |
|---|---|---|---|
| 서버 LLM 사실 추출 | 서버 LLM 없음 | 훅이 `claude -p haiku`로 추출 | 세션 밖 |
| 서버 측 중복 판정 | 없음 | 벡터로 후보 5개, `claude -p`가 ADD, UPDATE, SKIP 판정 | 세션 밖 |
| 자동 카테고리, 다중 라벨 | 없음 | metadata.type 단일 값. 훅은 출처를, MCP 쓰기는 Claude가 선택 | 둘 다 |
| 그래프 메모리, 개체 가산점 | 개체 저장소는 OSS에도 있고 켜져 있다. spaCy가 없으면 조용히 0점이 된다. 관계를 필드로 저장했던 외부 그래프 DB는 상류에서 제거 | 가산점은 후보 안 순서까지만 바꾸므로, 기억을 모으는 일은 병렬 다중 검색과 기억 병합이 맡음 | 세션 안, 서버 |
| 프로젝트 요약 API | 없음 | 만들지 않음. 검색 주입과 통합이 요약 역할 | 세션 안 |
| LLM 리랭커 | REST에 파라미터가 없어 서버를 패치해 열었다 | 서버가 후보 40개를 로컬 크로스인코더로 top_k까지 좁히고, Claude가 그 결과를 읽고 고름 | 서버, 세션 안 |
| 호출별 custom_instructions | 서버는 전역 1개 | 추출 프롬프트가 호스트에 있으니 불필요 | 세션 밖 |
| 일괄 갱신, 삭제 API | 없음 | Claude가 MCP update와 delete를 병렬 호출. 통합은 스크립트 루프 | 둘 다 |
| 내보내기 API | 없음 | 스킬이 get_memories로 전부 받아 마크다운으로 저장 | 세션 안 |
| 비동기 이벤트 상태 조회 | 로컬은 동기 | 불필요. 응답에 id가 바로 옴 | 없음 |
| 수면 통합 | 클라우드에도 없음 | `claude -p sonnet` + launchd 무인 실행 | 세션 밖 |
